# <a id="whats-new-in-10"></a>✨ What's New in Hush 1.0

### 💎 High-Sensitivity Optical Liquid Glass
- **Precision Sliders**: Tuned with real AGSL `RuntimeShader` mathematics for immediate, dramatic visual impact.
- **Backdrop Blur Slider (`0%–100%`)**: Fine-tune depth diffusion from ultra-transparent crystal to rich frosted glass.
- **Depth Effect & Refraction**: Multi-layered specular highlights, realistic 3D bevels, and optical edge dispersion.
- **Adaptive Contrast Icons**: Tab bar and mini-player icons dynamically shift into a deeper, rich accent tone for effortless readability.

### 🎨 Material 3 Expressive (M3E) Player
- **Tactile Bouncy Springs**: Vertical player swipes respond with organic M3E physics (`dampingRatio = 0.72f`, `stiffness = 340f`).
- **Beat-Sync Rotating Artwork Shapes**: 120 FPS rotating geometric frames that pulse dynamically to real-time audio amplitude peaks.
- **Edge-to-Edge Elegance**: Full status bar padding prevents clipping with system clocks and punch-hole camera cutouts.

### 🎤 Dynamic Stretchy & Variable-Weight Lyrics
- **Google Dialer Caller-Card Typography**: Active lyric lines expand dynamically (`scaleX`/`scaleY`), animate smoothly in ultra-bold `FontWeight.Black` (28sp), and sync live with extracted album art colors.
- **Ambient Glow Shadow**: Vibrant colored text glow surrounds current lines for enhanced contrast.
- **Graceful Static Fallback**: Automatically renders clean, readable static lyrics whenever synchronized timestamps are unavailable.

### 🎛️ Built-In Song Mixer & Remix Studio
- **Speed & Tempo**: Non-destructive audio stretching from `0.5x` to `1.5x`.
- **Pitch Shift**: Micro-tune playback pitch from `0.5x` to `1.5x` in real time.
- **Dual-Track Crossfade**: Smooth track overlapping configurable from `0s` to `12s`.
- **1-Tap Studio Presets**: Instantly trigger **Slowed + Reverb**, **Nightcore**, **Bass Boost**, and **Vaporwave**.

### 📊 Procedural 120 FPS Jetpack Compose Seekbars
- Choose between four custom procedural waveform progress styles:
  - **Straight**: Sleek Material 3 circular pill thumb with responsive scrub highlights.
  - **Wavy**: High-frequency animated acoustic sine wave.
  - **Dotted**: Stepped rhythm beacons with dynamic pulse illumination.
  - **Pulse**: Real-time heartbeat audio spikes.
- Progress updates run strictly isolated from UI recomposition trees, locking animations at **120 FPS**.

### ⌚ Wear OS Companion (HushWear)
- Complete Wear OS companion application providing watch-based media controls, volume adjustment, and playback management.
